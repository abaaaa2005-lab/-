# Всё Лаунчер 🚀

Лаунчер (рабочий стол) для Android, в котором есть буквально всё: сам рабочий стол, умный поиск, погода, заметки, задачи и десяток встроенных инструментов. Без рекламы, без аккаунтов, без сбора данных.

## Возможности

### Рабочий стол
- Большие часы (24/12 ч, с секундами или без), дата, заряд батареи и приветствие по имени
- Нажатие на часы открывает будильники, на дату открывает календарь
- Погода с прогнозом на 5 дней (Open-Meteo, без ключей), город выбирается в настройках
- Строка поиска
- Панель быстрых инструментов: фонарик, калькулятор, заметки, задачи, таймер, секундомер, компас, конвертер
- Виджет невыполненных задач
- Избранные приложения в сетке (от 3 до 7 колонок)
- Док: телефон, сообщения, все приложения, браузер, камера

### Жесты
| Жест | Действие |
|---|---|
| Свайп вверх | Все приложения |
| Свайп вниз | Шторка уведомлений |
| Двойной тап | Заблокировать экран (нужна служба спец. возможностей) |
| Долгое нажатие на пустом месте | Меню рабочего стола (обои, настройки, инструменты) |
| Свайп вниз в списке приложений | Закрыть список |

### Меню приложений
- Сортировка по алфавиту, по частоте запусков или по дате установки
- Раздел «Часто используемые»
- Долгое нажатие на приложение: вынести на главный экран, переместить, переименовать, скрыть, открыть сведения, удалить
- Скрытые приложения (их можно вернуть в настройках)
- Поддержка рабочего профиля

### Универсальный поиск
Одна строка ищет сразу по всему:
- приложения (включая неточное совпадение)
- калькулятор прямо в поиске: `2+2*2`, `sqrt(16)`, `15%`, `sin(30)`
- встроенные инструменты
- системные настройки: Wi-Fi, Bluetooth, батарея, экран, звук и ещё около 15 разделов
- контакты с кнопками звонка и SMS
- набор номера
- открытие сайта, поиск в Google/Яндекс/DuckDuckGo/Bing, на картах, на YouTube, в Play Маркете, перевод
- сохранение текста как заметки или задачи одним нажатием

### Встроенные инструменты (13 шт.)
Калькулятор (с инженерными функциями и историей) · Заметки (поиск, «Поделиться») · Задачи (с прогрессом) · Погода · Фонарик (с режимом SOS) · Секундомер (с кругами) · Таймер (со звуком и вибрацией) · Компас · Уровень · Конвертер величин (8 категорий) · Счётчик · Случайность (кубик, монетка, число, «выбери за меня») · Сведения об устройстве (ОЗУ, память, батарея)

### Настройки
Темы: системная, светлая, тёмная и AMOLED. Цвета Material You или один из 10 акцентных цветов. Можно менять размер иконок, число колонок, затемнение обоев и подписи под иконками, включать и выключать каждый блок рабочего стола, выбирать поисковик и город для погоды.

## Установка

1. Скачайте APK: вкладка **Actions** → последняя сборка → артефакт `vse-launcher-apk`.
   Или соберите сами: `./gradlew assembleDebug`, APK появится в `app/build/outputs/apk/debug/`.
2. Установите APK на телефон (разрешите установку из неизвестных источников).
3. Нажмите «Домой» и выберите **Всё Лаунчер**. Или откройте Настройки лаунчера → «Сделать лаунчером по умолчанию».
4. Чтобы блокировать экран двойным тапом, включите службу «Всё Лаунчер: блокировка экрана» в разделе «Спец. возможности».

Требуется Android 8.0 или новее.

## Технологии
Kotlin · Jetpack Compose · Material 3. Внешних библиотек, кроме AndroidX, нет. Данные хранятся локально в SharedPreferences.
